# Azharul Habib — Personal Portfolio

Live Website: [https://azharulhabib.pages.dev](https://azharulhabib.pages.dev)

The personal portfolio website of Azharul Habib, Software Engineer and Machine Learning Developer. Built with an obsidian dark aesthetic, custom responsive architecture across mobile, tablet, and desktop viewports, and an interactive HTML5 Canvas particle assembly engine.

## Tech Stack

- Framework: React 19
- Build Tool: Vite
- Styling: Tailwind CSS v4
- Icons: Lucide React
- Hosting: Cloudflare Pages

## Key Features

- Dynamic ASCII Particle Portrait: Custom HTML5 Canvas physics engine with dynamic coordinate sampling, particle convergence, and Retina DPR scaling.
- Viewport Architectures: Bespoke layouts tailored specifically for mobile (<768px), tablet (768px-1023px), and desktop (>=1024px) screens.
- Unified Grid System: Consistent global alignment and zero cumulative layout shift (CLS).
- Dark Theme Pre-render: Inline critical CSS ensuring zero white-flash on initial page load.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
